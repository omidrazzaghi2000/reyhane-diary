# 🌸 レイハーネの日記 — دفترچه‌ی ریحانه

<div dir="rtl">

یک وب‌اپ کوچک، خوشگل و دخترانه با تم ژاپنی (کائوایی + کلی‌مورفیسم) تا ریحانه خاطرات روزانه‌اش را **به زبان ژاپنی** بنویسد؛ مثل یک وبلاگ شخصی. بدون سرور، بدون لاگین، همه چیز روی خودِ دستگاه ذخیره می‌شود و با یک کلیک به گیت‌هاب پشتیبان‌گیری می‌شود.

## ✨ امکانات

- **خانه:** سلامِ روز، تاریخ ژاپنی، آمار (روزهای پیاپی، تعداد خاطرات، حروف نوشته‌شده، واژه‌ها)، «موضوع امروز» برای ایده گرفتن، درختِ شکوفه که با هر خاطره رشد می‌کند، نشان‌ها (badge).
- **نوشتن:** تاریخ، عنوان، حال و هوا (۷ صورتک)، آب‌وهوا، برچسب، متن با شمارنده‌ی حروف، **پنل کمکی** با جدول هیراگانا/کاتاکانا، جمله‌های آماده، کائوموجی و استیکرهای ژاپنی. پیش‌نویس خودکار ذخیره می‌شود.
- **خاطرات:** نمای فهرست یا **تقویم**، جستجو، فیلتر مورد علاقه، خواندن با مُهر (判子) به اسم ریحانه، ویرایش، حذف با امکان «بازگردانی».
- **دفتر واژه‌ها:** واژه + تلفظ + معنی، و حالت **فلش‌کارت** برای تمرین.
- **تنظیمات:** نام، زبان رابط (日本語 / فارسی / English)، ۴ تم (ساکورا، ماچا، سورا، یوزورا/شب)، گلبرگ‌های در حال ریزش، پشتیبان‌گیری، همگام‌سازی گیت‌هاب.
- **دیتابیس مشترک روی گیت‌هاب:** همه همان خاطرات را می‌بینند؛ هیچ داده‌ای در localStorage نیست.
- **حالت ویرایش با رمز 0000:** بازدیدکننده‌ها فقط می‌خوانند؛ نوشتن و ویرایش فقط با رمز ریحانه (و توکن روی دستگاه خودش).
- **PWA:** قابل نصب روی گوشی/تبلت، آفلاین هم کار می‌کند.
- دسترس‌پذیری: کنتراست مناسب، ناوبری با کیبورد، تاچ‌تارگت ≥۴۴px، احترام به `prefers-reduced-motion`.

## 💾 داده‌ها کجا ذخیره می‌شوند؟ (دیتابیس مشترک روی گیت‌هاب)

**یک فایل برای همه:** `data/diary.json` در همین ریپو دیتابیس است. هر کسی سایت را باز کند همان خاطرات را می‌بیند؛ هیچ خاطره‌ای در localStorage مرورگر نگه داشته نمی‌شود (فقط تنظیمات دستگاه مثل تم، زبان و توکن).

- **بازدیدکننده‌ها:** سایت فایل `data/diary.json` را از GitHub Pages می‌خواند (بدون توکن، بدون محدودیت).
- **ریحانه (دستگاه ویرایشگر):** اپ با توکن، همان فایل را از GitHub API می‌خواند (همیشه تازه‌ترین نسخه) و هر ذخیره را مستقیم در ریپو commit می‌کند. قبل از هر نوشتن، آخرین نسخه‌ی ریپو را می‌گیرد و با تغییرات ادغام می‌کند (حذف‌ها با tombstone ردگیری می‌شوند) تا چیزی گم نشود؛ حتی اگر از دو دستگاه بنویسد.
- **بعد از هر ذخیره:** یک کپی تاریخ‌دار در `data/backups/` نوشته می‌شود، ورک‌فلو `backup.yml` کپی دیگری در `backups/` می‌گذارد، و ورک‌فلو `deploy.yml` سایت را دوباره منتشر می‌کند تا بازدیدکننده‌ها (۱ تا ۲ دقیقه بعد) نسخه‌ی جدید را ببینند.
- **فایل JSON:** از تنظیمات می‌شود کپی گرفت (همه) یا فایل را ایمپورت و ادغام کرد (فقط ویرایشگر).

## 🔒 حالت ویرایش (فقط ریحانه، رمز 0000)

سایت برای همه **فقط‌خواندنی** است. نوشتن، ویرایش، حذف، ایمپورت و تغییر نام فقط بعد از وارد کردن رمز باز می‌شوند. رمز اولیه **`0000`** است (راهنمایی: «۴ تا عدد یکسان») و از تنظیمات → حالت ویرایش قابل تغییر است. هش رمز داخل `data/diary.json` است، پس روی همه‌ی دستگاه‌ها یکی است.

دو لایه وجود دارد:

| لایه | چه کسی | برای چه |
|---|---|---|
| **رمز 0000** | ریحانه، هر بار | قفل روزانه‌ی رابط کاربری: دکمه‌ی قفل در هدر یا بنر خانه. تیک «روی این دستگاه به خاطر بسپار» یعنی دفعه‌ی بعد نمی‌پرسد. |
| **توکن گیت‌هاب** | یک بزرگ‌تر، یک‌بار روی هر دستگاه ریحانه | اعتبار واقعی نوشتن در ریپو. بدون آن، ذخیره پیام می‌دهد «یک بزرگ‌تر باید توکن را وارد کند». |

یک سایت استاتیک نمی‌تواند بدون توکن در گیت‌هاب بنویسد و توکن را هم نمی‌شود عمومی در سایت گذاشت؛ به همین دلیل توکن فقط روی دستگاه خود ریحانه (تنظیمات → GitHub sync) ذخیره می‌شود. ساخت توکن: [DEPLOY.md](DEPLOY.md).

**اگر رمز فراموش شد:** چون هش در `data/diary.json` است، کافی است در گیت‌هاب فایل را ویرایش کنید و مقدار `"lock"` را `null` بگذارید (یا با یک بزرگ‌تر روی دستگاه ویرایشگر: تنظیمات → حالت ویرایش → پس از باز کردن قفل، رمز جدید). بعد از `null` شدن، اپ باز است و می‌توان رمز جدید ساخت.

## 🚀 اجرا

- لوکال: کافی است `index.html` را باز کنید، یا بهتر:

```bash
python3 -m http.server 8080
```

و به `http://localhost:8080` بروید.

- آنلاین: راهنمای کامل در [DEPLOY.md](DEPLOY.md).

## 🔐 نکته‌ی امنیتی

توکن گیت‌هاب در localStorage همان مرورگر ذخیره می‌شود. از **Fine-grained token** فقط با دسترسی `Contents: Read and write` روی همان یک ریپو استفاده کنید و تاریخ انقضا بگذارید. اگر ریپو عمومی است، خاطرات هم عمومی می‌شوند؛ در [DEPLOY.md](DEPLOY.md) سناریوی «ریپوی خصوصی برای داده» توضیح داده شده.

## English

A kawaii, claymorphism-styled personal diary web app for Reyhane (age 11–12) to write her daily life **in Japanese**. No backend: the diary is ONE shared file in this repo (`data/diary.json`) — every visitor reads the same diary from GitHub Pages, and the editor device writes it through the GitHub API with a merge-before-write (tombstones for deletes), dated backup copies and a backup workflow. Nothing is kept in localStorage except device settings. Password-protected editor mode (visitors read, only Reyhane writes; default password `0000`, changeable), installable PWA, works offline, UI in Japanese / Persian / English, four themes, accessible (contrast, keyboard, 44px targets, reduced-motion).

Run locally with `python3 -m http.server 8080`, deploy via GitHub Pages — see [DEPLOY.md](DEPLOY.md).
